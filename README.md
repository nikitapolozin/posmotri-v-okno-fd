# УЧЕБНЫЙ ПРОЕКТ ЯНДЕКС.ПРАКТИКУМ «ПОСМОТРИ В ОКНО»

Суть проекта: веб-страница (приложение), что даёт возможность "подсмотреть" за пейзажем выбранного города.

## Функциональность

- реализована возможность ввода города в поисковой строке;
- реализована возможность выбора времени суток для показа;
- реализован скрол с вариантами городов;
- по клику на кнопку «посмотреть еще» появляется дополнительный перечень городов.
