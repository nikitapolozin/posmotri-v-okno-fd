# Посмотри в окно 🪟
 
Учебный проект курса «Фронтенд-разработчик» от ЯндексПрактикума (спринт 3, блок «Адаптивность и графика»).
 
**[Демо-страница](https://nikitapolozin.github.io/posmotri-v-okno-fd/)**
 
## Описание
 
Веб-приложение для просмотра видеотрансляций из разных городов мира. Пользователь может выбрать время суток и город через форму поиска, посмотреть список доступных видео-«окон» в виде карточек и переключаться между ними, кликая по карточке — выбранное видео воспроизводится в крупном блоке на странице.
 
Проект получен в виде частично готовой заготовки: вся HTML-разметка, логика на JavaScript (получение данных, обработка кликов и отправки формы, генерация карточек через `<template>`, отображение прелоадеров и сообщений об ошибках) были предоставлены сразу. **Моя задача — написать CSS с нуля**, чтобы интерфейс полностью соответствовал дизайн-макету, не трогая при этом готовую разметку и работающую функциональность.
 
## Что было сделано
 
- Собран общий лейаут страницы на Flexbox (центрирование блока `.content`, распределение `.search-form`, растягивание `.content__details`)
- Настроены точные размеры и отступы компонентов в соответствии с макетом
- Оформлены текстовые стили: заголовки, обрезка переполняющегося текста (`text-overflow`, `line-clamp`), межстрочный интервал
- С нуля свёрстаны кастомные элементы форм — чекбоксы и текстовое поле — с использованием паттерна `.visually-hidden` для скрытия нативных элементов
- Стилизованы интерактивные состояния: `:hover`, `:active`, `:focus-visible` — для кнопок, карточек, чекбоксов и текущей выбранной карточки
- Реализовано позиционирование прелоадеров поверх видео-блока и списка карточек

## Технологии
 
- HTML5 (семантическая разметка, теги `<template>`)
- CSS3 (Flexbox, псевдоклассы и псевдоэлементы, `object-fit`, `line-clamp`, `:has()`)
- JavaScript (готовая логика — предоставлена в заготовке проекта)

## Чему научился
 
- Вёрстка по макету с точным соблюдением отступов, размеров и типографики
- Работа с частично готовым модулем — дописывание стилей поверх существующей разметки и скриптов без нарушения функциональности
- Кастомизация нативных элементов форм с сохранением доступности
- Использование псевдоклассов состояний (`:focus-visible`, `:has()`, `:checked`) для интерактивности без JS

## Как запустить локально
 
```bash
git clone git@github.com:nikitapolozin/posmotri-v-okno-fd.git
cd posmotri-v-okno-fd
```
 
Открыть файл `index.html` в браузере (либо через расширение Live Server в редакторе кода).
